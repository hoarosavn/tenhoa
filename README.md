# Tên các loài hoa: tiếng Việt, tiếng Anh, tên khoa học

Bảng tra 84 loài hoa quen thuộc ở Việt Nam, gồm tên tiếng Việt, tên gọi khác, tên tiếng Anh, tên khoa học, họ thực vật, mùa hoa và ý nghĩa thường gặp.

**Xem bảng tra:** https://hoarosavn.github.io/tenhoa/

## Dữ liệu

Tệp [`ten-hoa.json`](ten-hoa.json), mỗi loài gồm:

| Trường | Nội dung |
|---|---|
| `ten` | Tên tiếng Việt thường dùng |
| `tenKhac` | Tên gọi khác (nếu có) |
| `tiengAnh` | Tên tiếng Anh |
| `tenKhoaHoc` | Tên khoa học (`spp.` = nhiều loài trong chi, `×` = cây lai) |
| `ho` | Họ thực vật |
| `nhom` | Hoa cắt cành, hoa lan, hoa Tết, hoa cây cảnh & cây phố, hoa dại & hoa theo mùa |
| `mua` | Mùa hoa ở Việt Nam |
| `yNghia` | Ý nghĩa thường gặp khi tặng hoặc trong văn hóa |
